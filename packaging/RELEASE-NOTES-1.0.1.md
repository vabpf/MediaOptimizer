# Scripted release 1.0.1

Adds an optional Start menu entry. Nothing about the compression behaviour changed.

## New: Start menu shortcut

`Create-Shortcut.cmd` — run once, from wherever you unpacked the release.

It copies the runtime files to `%LOCALAPPDATA%\Programs\MediaOptimizer` and creates a
Start menu shortcut with a proper icon, so Media Optimizer appears in Start search and
under **All apps**. The downloaded folder can then be deleted.

```
Create-Shortcut.cmd             install + add the Start menu entry
Create-Shortcut.cmd -NoInstall  shortcut only, keep the files where they are
Create-Shortcut.cmd -Remove     undo both
```

Per-user only: no admin rights, no registry writes, no services, no PATH changes.
Uninstalling is deleting one folder and one shortcut — which `-Remove` does for you.

### Why you still click "Pin to Start"

Windows 10 and 11 have no supported API for an application to pin itself to Start; the
old `pintostart` verb was removed. Any tool claiming to do it is either using a
blocked hack or an unsupported Enterprise-only layout import.

So the shortcut lands in the Start menu and is searchable immediately, and pinning is
one right-click:

1. Press the Windows key and type `media optimizer`
2. Right-click the result
3. **Pin to Start**

## Icon

`MediaOptimizer.ico` — a nine-size icon (16 through 256 px, PNG-compressed frames) so the
Start entry and taskbar rendering do not fall back to the generic console icon. It is
generated by `packaging/make-icon.ps1`, committed as a binary, and regenerated only when
the artwork changes.

## Requirements

Unchanged from 1.0.0.

| Tool | Needed for | Install |
|---|---|---|
| `ffmpeg` / `ffprobe` | videos | `winget install Gyan.FFmpeg` |
| `cjpegli` | photos | not on winget — see libjxl releases |
| `exiftool` | timestamps (optional) | `winget install PhilHarvey.ExifTool` |

The launcher checks only for what your selection needs.

## Known limitations

Unchanged: video encoding is AMD-only (`hevc_amf`), subtitle and attachment tracks are
not copied, and an encode that grows the file is still kept.

## Upgrading from 1.0.0

Unpack over the top, or run `Create-Shortcut.cmd` to install the new copy. If you
already installed 1.0.0's folder by hand, run `Create-Shortcut.cmd -Remove` first.
